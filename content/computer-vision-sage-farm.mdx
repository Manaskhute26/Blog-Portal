Agriculture remains the backbone of the Madhya Pradesh economy. At the **SAGE Agricultural AI Innovation Hub**, our undergraduate research team engineered a low-latency computer vision pipeline designed for real-time crop disease detection on embedded microcontrollers.

## Mathematical Formulation of Bounding Box Intersection

The Intersection over Union (IoU) metric used to evaluate bounding box prediction precision is defined as:

$$
\text{IoU} = \frac{\text{Area}(B_p \cap B_g)}{\text{Area}(B_p \cup B_g)}
$$

Where $B_p$ is the predicted bounding box and $B_g$ is the ground-truth annotation box.

```javascript
// Edge inference payload processor for SAGE Smart Farm Sensors
function processDetectionFrame(predictions, confidenceThreshold = 0.85) {
  return predictions
    .filter(item => item.confidence >= confidenceThreshold)
    .map(detection => ({
      class: detection.className,
      confidence: `${(detection.confidence * 100).toFixed(1)}%`,
      coordinates: detection.bbox,
      timestamp: new Date().toISOString()
    }));
}

console.log(processDetectionFrame([
  { className: "Early Blight Spot", confidence: 0.94, bbox: [120, 45, 200, 180] }
]));
```

## Field Trial Results

Our deployment on the SAGE University experimental agricultural farm achieved **94.2% Mean Average Precision (mAP@0.5)** while consuming under **3.5 Watts** of power.
